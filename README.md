# 100 Days of DevOps 🚀

## About This Challenge

Welcome to my **100 Days of DevOps** journey!

I'm completing hands-on labs through **KodeKloud** to strengthen my technical skills, gain practical experience, and continue building toward my goal of becoming a Cloud/DevOps Engineer.

My focus is on learning by doing, improving my troubleshooting abilities, and becoming more confident working independently.

## 🛠️ Technologies & Skills

Throughout this challenge, I'll be practicing:

- Linux Administration
- Git & GitHub
- Docker & Kubernetes
- CI/CD Pipelines
- Terraform & Infrastructure as Code
- Networking & Troubleshooting
- Automation & Scripting

## 🎯 My Goals

- Complete 100 hands-on DevOps labs.
- Strengthen my Linux and infrastructure skills.
- Practice researching documentation and solving problems independently.
- Document what I learn along the way.
- Build practical skills applicable to Cloud Support, DevOps, and SRE roles.

## 📚 Learning Approach

1. Read and understand the lab scenario.
2. Research official documentation when needed.
3. Implement and troubleshoot the solution.
4. Verify the results.
5. Document key takeaways.
